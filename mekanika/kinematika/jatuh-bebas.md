# Jatuh Bebas
Tanpa hambatan udara, jarak jatuh sebanding dengan kuadrat waktu.

{% include sim.html id="jatuh-bebas" %}

$$h = \tfrac12 g t^2 \quad\Longrightarrow\quad g = \frac{2h}{t^2}$$

{: .note }
> - Dengan $$b = 0$$, grafik $$a$$–$$t$$ datar di nilai $$g$$.
> - Grafik $$v$$–$$t$$ lurus: kemiringannya adalah $$g$$.
> - Dengan $$b > 0$$, $$a$$ turun saat $$v$$ bertambah.

{: .try }
> - Catat $$t$$ jatuh untuk lima $$h$$ berbeda, lalu hitung $$g = 2h/t^2$$.
> - Set $$b = 0{,}14$$ (bola pingpong). Berapa persen $$g$$ hasil hitung meleset?

{: .assume }
> - Dilepas dari diam; tidak memantul di lantai.
> - Hambatan udara $$a = g - b\,v^2$$ dengan $$b = \rho C_d A / 2m$$.
> - $$b = 0$$ adalah kasus ideal (kelereng).
