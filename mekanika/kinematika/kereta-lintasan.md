# Kereta pada Lintasan
Di bidang miring kereta dipercepat tetap; di bagian datar lajunya tetap.

{% include sim.html id="kereta-lintasan" %}

$$x = \tfrac12 a t^2, \qquad a = g\sin\theta$$

{: .note }
> - Grafik $$s$$–$$t$$ melengkung di bidang miring, lurus di bagian datar.
> - Grafik $$v$$–$$t$$ naik linear lalu mendatar; $$a$$ melompat ke nol di sambungan.
> - Dengan $$\mu > 0$$, $$a$$ di bidang miring lebih kecil dari $$g\sin\theta$$.

{: .try }
> - Gandakan $$\theta$$ dari 2,5° ke 5°. Apakah $$a$$ ikut berlipat dua?
> - Naikkan $$\mu$$ sampai kereta berhenti sebelum penahan. Berapa $$\mu$$ saat itu?

{: .assume }
> - Kereta dianggap titik massa; lintasan miring 1,0 m lalu datar 1,0 m.
> - Dilepas dari diam; sambungan mulus, laju tidak berubah.
> - Gesekan kinetis $$\mu$$ sama di kedua bagian.
