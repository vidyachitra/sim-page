# Koordinat Kartesius, Silinder, dan Bola
Satu titik dalam ruang punya tiga deskripsi: $$(x, y, z)$$, $$(\rho, \varphi, z)$$, atau $$(r, \theta, \varphi)$$.

{% include sim.html id="koordinat-3d" %}

$$x = r\sin\theta\cos\varphi,\quad y = r\sin\theta\sin\varphi,\quad z = r\cos\theta$$

{: .note }
> - Silinder: $$x = \rho\cos\varphi$$, $$y = \rho\sin\varphi$$, $$z$$ sama; $$\rho = r\sin\theta$$.
> - Heliks: $$\rho$$ tetap. Spiral pada bola: $$r$$ tetap.
> - $$\hat\rho$$, $$\hat\varphi$$, $$\hat r$$, $$\hat\theta$$ berubah arah; $$\hat k$$ tidak.

{: .try }
> - Putar sudut pandang dan elevasi 90°. Tampak apa dari atas?
> - Pada titik tetap, bandingkan $$\rho$$ dengan $$r\sin\theta$$.

{: .assume }
> - $$\theta$$ dari sumbu $$+z$$ (0°–180°); $$\varphi$$ dari $$+x$$ ke $$+y$$.
> - Lintasan ditentukan langsung oleh fase $$\omega t$$, bukan oleh gaya.
> - Proyeksi ortografik; vektor satuan digambar sepanjang 0,3 m.
