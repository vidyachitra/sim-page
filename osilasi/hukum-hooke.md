# Hukum Hooke dan Susunan Pegas
Regangan pegas sebanding dengan gaya; susunan seri lebih lunak, paralel lebih kaku.

{% include sim.html id="hukum-hooke" %}

$$F = kx, \qquad \frac{1}{k_s} = \frac{1}{k_1} + \frac{1}{k_2}, \qquad k_p = k_1 + k_2$$

{: .note }
> - Beban sama, regangan berbeda: seri paling panjang, paralel paling pendek.
> - Pada seri, pegas yang lebih lunak meregang lebih banyak.
> - Grafik $$k$$ efektif tidak bergantung pada $$m$$.

{: .try }
> - Set $$k_1 = k_2$$. Periksa: $$k_s = k/2$$ dan $$k_p = 2k$$?
> - Gandakan $$m$$. Apakah ketiga regangan ikut berlipat dua?

{: .assume }
> - Pegas ideal tak bermassa, dalam batas elastis.
> - Regangan diukur dari posisi tanpa beban.
> - Perubahan beban ditampilkan sebagai relaksasi halus, bukan osilasi.
