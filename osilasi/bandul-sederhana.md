# Bandul Sederhana
Bandul bertukar energi kinetik dan potensial; periodenya hanya bergantung pada panjang tali dan $$g$$.

{% include sim.html id="bandul-sederhana" %}

$$T = 2\pi\sqrt{\frac{L}{g}} \quad\Longrightarrow\quad T^2 = \frac{4\pi^2}{g}\,L$$

{: .note }
> - EK puncak di titik terendah, EP puncak di ujung ayunan.
> - Dengan $$b = 0$$, garis $$E$$ tetap datar.
> - Sudut besar berayun lebih lambat dari rumus sudut kecil.

{: .try }
> - Ukur $$T$$ dari grafik $$\theta$$–$$t$$ untuk lima $$L$$, lalu hitung $$g = 4\pi^2 L/T^2$$.
> - Bandingkan $$T$$ pada $$\theta_0 = 10°$$ dan $$90°$$. Seberapa jauh dari $$T_0$$?

{: .assume }
> - Titik massa pada batang kaku tak bermassa.
> - Tanpa pendekatan sudut kecil.
> - Redaman sebanding dengan kecepatan sudut.
