# Hukum II dan Entropi
Gas menyebar karena keadaan tercampur jauh lebih banyak cara tersusunnya daripada keadaan terpisah.

{% include sim.html id="entropi" %}

$$S = k \ln \Omega$$

{: .note }
> - Setelah sekat dibuka, $$n_{kiri}$$ menuju $$N/2$$ lalu hanya berfluktuasi.
> - Kurva $$\ln \Omega$$ memuncak tajam di tengah; di sana entropi maksimum.
> - $$N$$ kecil berfluktuasi besar; $$N$$ besar hampir tak pernah kembali.

{: .try }
> - Buka sekat dengan $$N = 4$$, lalu dengan $$N = 200$$; bandingkan fluktuasinya.
> - Tutup sekat lagi setelah tercampur; apakah entropi turun?

{: .assume }
> - Partikel ideal tanpa tumbukan antarpartikel, hanya pantulan dinding.
> - Entropi butir kasar: hanya dihitung kiri atau kanan.
> - $$\Omega = \binom{N}{n_{kiri}}$$; mode 2 mengalikan dua koefisien binomial.
