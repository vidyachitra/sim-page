# Bimetal dan Termostat
Dua logam dengan muai berbeda melengkung saat dipanaskan dan memutus pemanas secara otomatis.

{% include sim.html id="bimetal" %}

$$\kappa = \frac{3(\alpha_1-\alpha_2)\,\Delta T}{2h}$$

{: .note }
> - Lapisan dengan α lebih besar selalu berada di sisi luar lengkungan.
> - Suhu naik-turun di sekitar titik setel saat kontak membuka dan menutup.
> - Keping lebih tipis melengkung lebih kuat untuk kenaikan suhu yang sama.

{: .try }
> - Samakan $$\alpha_1$$ dan $$\alpha_2$$. Apakah pemanas masih bisa mati?
> - Perbesar celah kontak dan amati titik setel suhu naik.

{: .assume }
> - Kedua lapisan sama tebal dan sama modulus elastisnya.
> - Suhu keping merata; kalor hilang sebanding $$T - 25\ ^\circ\text{C}$$.
> - Kontak jentik: membuka pada celah + 0,5 mm, menutup pada celah.
