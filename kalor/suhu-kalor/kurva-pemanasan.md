# Kurva Pemanasan dan Kalor Laten
Saat es mencair dan air mendidih, kalor terus masuk tetapi suhu diam.

{% include sim.html id="kurva-pemanasan" %}

$$Q = m\,L$$

{: .note }
> - Kalor masuk naik lurus, juga selama suhu mendatar.
> - Dataran didih ≈ $$L_v/L_f$$ ≈ 6,8× lebih panjang dari dataran lebur.
> - Selama dataran, kalor memutus ikatan antarpartikel, bukan menaikkan suhu.

{: .try }
> - Ukur lama dataran lebur, lalu cocokkan dengan $$m L_f / P$$.
> - Gandakan daya. Apakah suhu dataran ikut berubah?

{: .assume }
> - Tekanan 1 atm, tanpa rugi kalor; kalor jenis tetap per wujud.
> - Pemanas mati saat uap mencapai 150 °C.
> - Partikel hanya gambaran, bukan simulasi molekul.
